# Design Defaults as Sustainability Lever

## Overview
Default settings significantly affect aggregate environmental impact. BBC iPlayer defaults to SD; Spotify defaults to 160Kbps. "Digital waste" (e.g., streaming video for audio-only use) represents unnecessary infrastructure load. Design choices shape user behavior at scale.

## Key Insight
Sustainable defaults can reduce environmental impact without requiring user action or awareness. The "cornucopian paradigm" (unlimited resources assumption) in design leads to wasteful defaults.
