# Generative UI Tools

*This tight cluster focuses specifically on generative user interface tools — AI systems that generate interface components, layouts, or code from natural language or prototype inputs. The papers share a design research orientation, examining what GenUI tools can and cannot do, how they fit into existing development workflows, and what their design space reveals about the role of human judgment in UI generation. The community sits as a focused sub-cluster within the broader GenAI in UX and Design Practice conversation.*
