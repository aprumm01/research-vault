# The GenUI Study Exploring the design of generative UI tools to support UX practitioners and beyond

## Summary
AI can now generate high-fidelity UI mock-up screens from a highlevel textual description, promising to support UX practitioners’ work However, it remains unclear how UX practitioners would adopt such Generative UI (GenUI) models in a way that is integral and beneficial to their work To answer this question, we conducted a formative study with 37 UX-related professionals that consisted of four roles: UX designers, UX researchers, software engineers, and product managers.

## Key Concepts
- Generative UI (GenUI) models and tools
- Prompt-based UI generation
- Cross-role UX collaboration (UX designers, UX researchers, software engineers, product managers)
- AI-assisted prototyping and mockup generation
- First draft generation vs. last mile refinement
- Democratization of UX design
- Workflow integration

## Theoretical Framework
Formative research examining technology adoption through role-specific analysis, grounded in understanding how different professional roles integrate new AI tools into existing workflows and collaborative practices.

## Methods
Week-long project-based diary study with 37 UX-related professionals from a large software company across four roles (11 UX designers, 7 UX researchers, 7 product managers, 12 software engineers). Participants completed role-specific mini-project exercises using a state-of-the-art GenUI tool, maintaining daily journals followed by semi-structured interviews.

## Main Arguments
- GenUI provides strong "first draft" capabilities but faces "last mile" challenges in refinement and finalization
- GenUI can support all roles in early-stage ideation, rapid first-draft prototyping, and visual communication
- GenUI democratizes UX design by enabling non-designers (PM, SWE, UXR) to create UI mockups
- Different roles adopt distinct workflows with GenUI based on their professional responsibilities
- Key gaps exist in problem formulation with context, intent assimilation, constrained generation, multimodal input/output, element connectivity, quality/fidelity/originality, and editing/iteration support
- GenUI should extend beyond individual UX tasks to support team-level collaborative activities

## Limitations & Critiques
- Study conducted within single large software company, limiting generalizability
- One-week timeframe may not capture long-term adoption patterns
- Participants used unfamiliar GenUI tool rather than their preferred design tools
- Most participants had limited prior GenUI experience, affecting learning curve observations
- Focus on individual workflows may underrepresent collaborative design challenges
