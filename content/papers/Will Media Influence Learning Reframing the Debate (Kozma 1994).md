# Will Media Influence Learning? Reframing the Debate (Kozma 1994)

## Connections
- [[Instructional Design Theory]] - `` [EXTRACTED]

## Summary
Richard Kozma's 1994 response to Clark reframes the media and learning debate by arguing that media and methods are not easily separable—the affordances of specific media enable certain instructional methods that other media cannot support. Kozma contends that as media become more sophisticated (particularly interactive multimedia), they create new cognitive possibilities for learning that go beyond simple delivery. He challenges Clark's delivery metaphor and advocates for research that examines learning with media, not just from media.

## Key Concepts
- Media and learning debate
- Media affordances
- Interactive multimedia
- Learning with media
- Cognitive tools

## Theoretical Framework
Cognitive psychology and symbol systems theory (Salomon) ground Kozma's argument that media's cognitive and symbolic features can support qualitatively different forms of learning activity.

## Methods
Theoretical argument and review; engagement with Clark's delivery model; review of evidence for media-specific learning effects from interactive and multimedia systems.

## Main Arguments
- Media and methods are not separable; specific media enable specific methods that others cannot
- Advanced media create cognitive affordances that support learning processes impossible in other media
- The question should be how to leverage media's unique capabilities for learning, not whether media matter
- Research should focus on learning with media (as cognitive tools) rather than just from media (as delivery vehicles)
