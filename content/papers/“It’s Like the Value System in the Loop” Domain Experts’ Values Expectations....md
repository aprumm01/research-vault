# "It's Like the Value System in the Loop": Domain Experts' Values Expectations for NLP Automation (Showkat & Baumer)

## Summary
Showkat and Baumer's paper investigates how domain experts in high-stakes fields (law, medicine, social work) express and negotiate their values expectations for NLP automation tools being designed for their professional contexts. Through interviews and participatory design sessions, the study documents how experts articulate values like accuracy, fairness, explainability, and human oversight — and how these values conflict with each other and with NLP system constraints. The paper contributes frameworks for values negotiation in NLP design and argues for more robust mechanisms for expert values participation in AI system development.

## Key Concepts
- Domain expert values expectations for NLP
- Values negotiation in AI design
- Human oversight and explainability in professional AI
- Accuracy vs. fairness tensions in NLP systems
- Participatory values-sensitive design for AI

## Theoretical Framework
Value Sensitive Design (VSD); participatory design; critical AI studies; draws on Friedman and Hendry's VSD framework and Baumer's prior work on resistance and non-use to examine values in professional NLP contexts.

## Methods
Participatory design sessions and interviews with domain experts (legal, medical, social work) about NLP tools designed for their fields; qualitative analysis of values expressions, tensions, and negotiation strategies.

## Main Arguments
- Domain experts hold complex, context-specific values expectations for NLP automation that generic AI ethics principles do not capture
- Values tensions (accuracy vs. fairness, efficiency vs. human oversight) are not resolvable through design alone — they require ongoing negotiation
- Expert participation in NLP design reveals hidden values that become visible only when experts encounter specific system behaviors
- "The value system in the loop" — keeping values-aware human judgment integrated with automated systems — is an expert demand that current NLP systems fail to fully support

## Limitations & Critiques
Study limited to three professional domains; the participatory design setting may elicit different values expressions than naturalistic AI deployment; NLP capabilities have advanced since the study, potentially changing the values landscape.
