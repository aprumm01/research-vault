# Cognitive Load Theory


## Summary
Cognitive Load Theory (CLT) holds that working memory is severely limited in capacity and duration, and that effective instruction must design within these constraints. Sweller identified three load types: intrinsic (complexity inherent to the task), extraneous (imposed by poor instructional design), and germane (productive effort toward schema construction). CLT has major implications for instructional design, multimedia learning, and interface design. In this research vault, CLT is relevant both as a foundational ID theory (applied in ADDIE and learning design) and as a frame for understanding how AI tools may offload cognitive work -- potentially reducing extraneous load while raising questions about whether germane load (and thus deep learning) is undermined.

## Key Concepts
- Intrinsic, extraneous, and germane cognitive load
- Working memory limitations and long-term memory schemas
- Instructional design principles: reducing extraneous load, managing intrinsic load
- Multimedia learning and split-attention effects (Mayer's extensions)
- AI as cognitive offloading tool: implications for CLT

## Theoretical Framework
Information processing theory; schema theory (Bartlett, Rumelhart); situated within cognitive psychology and instructional design research traditions; Sweller's 1988 foundational paper and subsequent CLT literature; connected in this vault to ID theory, HPT, and AI-mediated deskilling debates.
