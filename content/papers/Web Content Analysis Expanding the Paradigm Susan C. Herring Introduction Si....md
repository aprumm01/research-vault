# Web Content Analysis: Expanding the Paradigm Susan C. Herring Introduction Si...

## Summary
Herring (2010) introduces Web Content Analysis (WebCA) as an adaptation of classical content analysis to computer-mediated communication (CMC) and web content. The paper argues that the web is a distinct medium with structural, social, and textual dimensions that require methodological adaptation. WebCA combines quantitative coding of message features with qualitative interpretation, and includes attention to medium affordances, context, and researcher positionality. It is distinguished from discourse analysis by its emphasis on explicit, pre-specified coding schemes applied to observable units.

## Theoretical Framework
WebCA draws on classical content analysis traditions (Berelson, Krippendorff) while extending them to networked environments.
