# Integrating User Experience in User Interface Design Education (Huang, 2025)

## Summary
Reports a curriculum study at Yuan Ze University integrating UX principles into UI design education through a Problem-Based Learning approach augmented by generative AI tools. Using a 32-item questionnaire across five dimensions (PBL effectiveness, UX design, UI design, user testing, and GenAI-supported design), the study finds that GenAI tools enhanced creativity and iterative problem-solving when structured around real-world design challenges with industry professional input.

## Key Concepts
- **PBL + GenAI integration**: Combining Problem-Based Learning scaffolding with generative AI to augment design studio work
- **UX/UI curriculum integration**: Teaching UX principles and research methods within UI design coursework
- **Generative AI-supported design**: Using AI output as a design material within iterative studio critique

## Main Arguments
1. PBL structured around real-world challenges provides an effective scaffold for GenAI integration in design education
2. UX and UI design are frequently split in curricula; integration improves both outcome quality and student understanding
3. GenAI tools improve iteration speed and breadth of exploration when paired with structured critique
