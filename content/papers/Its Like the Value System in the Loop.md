# It’s Like the Value System in the Loop

## Summary
The rise of automated text processing systems has led to the development of tools designed for a wide variety of application domains These technologies are often developed to support non-technical users such as domain experts and are often developed in isolation of the tools primary user While such developments are exciting, less attention has been paid to domain experts’ expectations about the values embedded in these automated systems.

## Key Concepts
- **Value systems embedded in automated text processing systems**
- **Domain expert expectations** about NLP automation values
- Development of NLP tools in isolation from primary users (domain experts)
- Gap between developer and domain expert understanding of system values
- Non-technical users as target population for text processing systems
- Automated systems designed for various application domains
- Values and ethics in NLP automation

## Theoretical Framework
- **Value-sensitive design**: Understanding values embedded in technological systems
- **Participatory design**: Involving domain experts in technology development
- **Human-centered NLP**: Aligning automated systems with user values and expectations

## Methods
participatory design

## Main Arguments
- Automated text processing systems developed in isolation from domain expert users
- Less attention paid to domain experts' expectations about values embedded in NLP systems
- Tools designed for non-technical users require understanding of user values and expectations
- Value systems are implicit in automated decision-making and text processing
- Gap exists between exciting technological developments and attention to embedded values
- Domain expertise and technical development need better integration
- "Value system in the loop" metaphor captures importance of values in automation

## Limitations & Critiques
- Study context and specific application domains not fully specified
- Need for empirical data on domain expert expectations across various fields
- Challenge of operationalizing and measuring "values" in NLP systems
- Participatory design approach may not scale across all NLP application contexts
- Tension between system generalizability and domain-specific value alignment
- Limited guidance on resolving value conflicts between stakeholders
