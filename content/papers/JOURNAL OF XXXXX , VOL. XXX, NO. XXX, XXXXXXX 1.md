# From Disruptions to Discussions: How GenAI Impacts Human Interactions in Software Development

## Summary
This paper investigates how generative AI is disrupting and reshaping human interactions in software development teams, examining how AI coding assistants affect collaboration patterns, communication, and team knowledge distribution. Through a study of software development teams using AI code generation tools, the authors find that AI shifts developers' attention from production to review and integration, changes the social dynamics of pair programming and code review, and creates new coordination challenges around AI-generated code ownership and quality. The paper frames these as discussions that teams and organizations must engage proactively.

## Key Concepts
- Generative AI in software development teams
- AI coding assistant effects on collaboration
- Code review and quality assurance in AI-mediated development
- Knowledge distribution in AI-augmented teams
- Human interaction disruption in software development

## Theoretical Framework
CSCW; software engineering practices; human-AI teaming; draws on pair programming research, code review literature, and distributed cognition to analyze AI's effects on development team dynamics.

## Methods
Study of software development teams using AI coding assistants; qualitative interviews and surveys; analysis of development workflow changes; observation of code review and collaboration sessions.

## Main Arguments
- AI coding assistants shift the cognitive work of software development from generation to evaluation, requiring new review competencies
- Pair programming dynamics change when AI is the "partner": the social and epistemic functions of human pair programming are not replicated
- Team knowledge distribution shifts: AI knowledge is external to the team and opaque, creating new dependencies and single points of failure
- Organizations need deliberate policies about AI code use to prevent the erosion of collective code understanding

## Limitations & Critiques
Study conducted at a specific moment in AI coding tool adoption; rapidly improving capabilities may shift findings; team size and organizational context significantly affect findings; the software development context may not generalize to other collaborative work contexts.
