# Collaboration with Conversational AI Assistants for UX Evaluation: Questions and How to Ask Them

## Summary
Explores whether conversational AI assistants can support UX evaluators analyzing usability test recordings by enabling a question-and-answer dynamic, using a Wizard-of-Oz design probe study with 20 participants interacting via text or voice. Finds five categories of evaluator questions and that text interaction generates more questions and is perceived as more efficient, while both modalities earn similar satisfaction and trust ratings.
