# Using Generative AI to Support UX Design Students in Web Dev

## Summary
Buendía-García and Piris-Ruano (Universitat Politècnica de Valencia, 2025) investigate the integration of generative AI tools into web development courses for UX design students, published in Applied Sciences (June 2025). The study explores how GenAI can support students learning web development, a technical domain that is often challenging for students whose primary training is in UX and interaction design. The paper addresses a practical curriculum gap: UX design programs increasingly need students who can prototype and build functional interfaces, and GenAI tools offer a potential bridge between design skills and implementation capacity.

## Key Concepts
- GenAI as scaffolding for web development learning
- UX design students acquiring technical implementation skills
- Curriculum integration of AI tools in design education
- Prototyping and development bridge for non-programmer designers

## Theoretical Framework
Scaffolded learning / constructivism — GenAI as a scaffold that reduces technical barriers while students develop web development competencies alongside design skills.

## Methods
Educational intervention study in web development courses at UPV Valencia; likely involves pre/post assessment or comparison conditions. Published in Applied Sciences 2025 (22 pages, DOI: 10.3390/app15137389).

## Main Arguments
- GenAI tools can bridge the technical skills gap UX students face in web development courses
- AI-assisted development changes what students need to learn — shifts from syntax memorization toward specification and evaluation of generated code
- The instructor role changes when GenAI scaffolds are available — focus moves to design judgment rather than implementation mechanics
- Student outcomes (speed, quality of prototypes) may improve with AI support, but critical evaluation skills need explicit cultivation

## Limitations & Critiques
Single institutional context; findings may not transfer to programs with different student backgrounds or infrastructure. Published mid-2025, so limited citation record. Full findings not available in excerpt.
