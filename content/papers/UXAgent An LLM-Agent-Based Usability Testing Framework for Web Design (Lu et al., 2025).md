# UXAgent: An LLM-Agent-Based Usability Testing Framework for Web Design (Lu et al., 2025)

## Summary
This is the short conference version of UXAgent presented at CHI EA 2025 (Yokohama). Lu, Yao, Gu, Huang, Wang, Li, Gesi, He, Li, and Wang describe the core UXAgent system design: a Persona Generator, LLM Agent module with Universal Browser Connector, and Result Viewer. A preliminary heuristic evaluation with five UX researchers praised the innovation but raised concerns about the long-term implications of LLM agent usage in UX studies. The extended full paper provides more complete implementation details and a 16-researcher evaluation; this short version documents the initial system design and early expert feedback.

## Key Concepts
- UXAgent short version: CHI EA '25 (Extended Abstracts) conference paper
- Same core architecture as full version: Persona Generator, LLM Agent, Universal Browser Connector, Result Viewer
- Five-researcher heuristic evaluation (preliminary, pre full study)
- Key concern raised: implications of LLM agent normalization in UX practice
- Demo available at uxagent.hailab.io

## Theoretical Framework
Same as extended full paper; LLM agent and autonomous agent research; usability testing methodology; CHI Extended Abstracts 2025 (Yokohama, April-May 2025).

## Methods
System design documentation; heuristic evaluation with five UX researchers providing structured feedback on system utility, design, and concerns; qualitative thematic analysis of researcher comments.

## Main Arguments
- Same core arguments as the full paper, abbreviated: UXAgent enables pre-study design validation using LLM agent simulations on live websites
- The five-researcher preliminary evaluation confirms innovation perception but surfaces the same concern about LLM agent adoption in UX research practice

## Limitations & Critiques
Short conference paper format limits detail; five-researcher evaluation is too small for robust conclusions; this paper is superseded by the full extended version (P463) which should be the primary citation.
