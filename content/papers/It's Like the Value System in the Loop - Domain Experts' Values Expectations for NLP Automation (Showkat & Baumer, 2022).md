# "It's Like the Value System in the Loop": Domain Experts' Values Expectations for NLP Automation

## Summary

This DIS 2022 paper investigates how domain experts (investigative journalists and legal professionals) perceive values in automated NLP systems. Through participatory design fiction workshops, the researchers engaged non-technical professionals in speculating about future NLP tools designed for their work. The study reveals that domain experts deeply care about values such as autonomy, freedom from biases, privacy, trust, and human welfare in automated systems.

## Key Concepts

- **Values Expectations**: What values users expect to be embedded in technology
- **Design Fiction**: Speculative design method using fictional scenarios to elicit user perspectives
- **NLP Automation**: Automated natural language processing systems
- **Not-to-Design Implications**: Features or systems that should not be implemented
- **Domain Expertise**: Professional knowledge outside computing that shapes technology use

## Theoretical Framework

The paper integrates:

1. **Value Sensitive Design**: Proactively considering human values in technology design
2. **Design Fiction Methods**: Using speculative scenarios to engage stakeholders
3. **Participatory Design**: Involving users in design processes
4. **Critical Design**: Questioning assumptions through provocative designs

## Methods

- Participatory design fiction workshops with two non-profit organizations
- One workshop with investigative journalists, one with legal researchers
- Design fiction concepts: DocSelfSorter, DataWatch, VeriFact, VRNewsPal/VRLegalPal, TransparencyMonitor/CompassionMonitor
- Grounded theory analysis of workshop discussions
- Prior semi-structured interviews informing design fiction creation

## Main Arguments

1. Domain experts have distinct values expectations for NLP automation
2. Key values include: autonomy, freedom from biases, privacy, trust, human welfare
3. Tensions exist between automation benefits and professional values
4. Design fiction effectively elicits "not-to-design" implications
5. Domain experts should be included in NLP system design conversations

## Design Fiction Concepts

- **DocSelfSorter**: Automated document sorting and classification
- **DataWatch**: Smart watch for tracking data sources
- **VeriFact**: Automated fact-checking system
- **VRNewsPal/VRLegalPal**: VR reconstruction of news stories/court trials
- **TransparencyMonitor/CompassionMonitor**: Values monitoring in texts

## Limitations and Critiques

- Small sample size (8 participants across two organizations)
- Both organizations are non-profits; for-profit contexts may differ
- Design fictions are hypothetical; actual systems might elicit different responses
- US-based participants; cultural variation not explored
- Long-term value alignment not assessed
