# Cognitive Walkthrough

## Overview
Cognitive walkthrough is a structured usability inspection technique in which evaluators step through a task sequence and answer four standard questions at each step: Will users know what to do? Will users notice the correct action is available? Will users understand the system's feedback? The method simulates a novice user's exploratory learning process without recruiting real participants. In this corpus it is used as a benchmark to test whether LLM agents can replicate the issue-finding and task-completion patterns of human CW panels.
