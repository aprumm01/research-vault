# Think Aloud Protocol

## Overview
Think aloud is a data collection method in which participants verbalize their thoughts, intentions, and reactions while performing a task. It yields rich qualitative data about decision points, confusion, and mental models that behavioral logs alone cannot capture. In the synthetic user literature, think aloud serves a dual role: as ground-truth data collected from human participants in validation studies, and as a simulated output format generated by LLM agents to produce interpretable reasoning traces about interface interactions.
