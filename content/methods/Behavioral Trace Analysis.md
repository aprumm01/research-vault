# Behavioral Trace Analysis

## Overview
Behavioral trace analysis involves collecting and comparing logs of interaction sequences — click paths, query patterns, navigation behavior, time-on-task, and error events — rather than relying on self-report. In synthetic user research it is a primary alignment metric: do AI agents produce interaction traces that resemble those of real users? Zhou et al. formalize this into a six-dimension User Simulation Index (USI) covering communication style, information pattern, clarification behavior, error reaction, outcome calibration, and evaluative alignment. The method surfaces divergences invisible to outcome-only metrics (e.g., AI agents reaching correct decisions via systematically different paths than humans).
