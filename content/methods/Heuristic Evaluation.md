# Heuristic Evaluation

## Overview
Heuristic evaluation is a usability inspection method in which evaluators assess an interface against a set of established usability principles (most commonly Nielsen's 10 heuristics). It does not require user recruitment — trained evaluators (or, in recent work, LLM agents) walk through the interface and identify violations. In this corpus it appears both as a standalone evaluation method and as a benchmark for testing whether synthetic users can replicate expert human findings. Key metrics include issue discovery rate, severity ratings, and overlap with a master issue set.
